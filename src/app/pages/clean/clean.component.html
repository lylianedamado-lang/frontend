Méthode de normalisation :
À propos de cette méthode :

Min-Max Scaling : Transforme vos données numériques pour qu'elles soient comprises entre 0 et 1. Idéal pour les algorithmes sensibles à l'échelle. Z-Score Standardization : Centre vos données autour de 0 avec un écart-type de 1. Parfait pour les analyses statistiques. Robust Scaling : Utilise les quartiles pour réduire l'impact des valeurs extrêmes. Recommandé en présence d'outliers.
